# ZKTeco SenseFP M1 হাজিরা ডাটা অটোমেশন গাইড

ZKTeco SenseFP M1 ডিভাইসের নিজস্ব ক্লাউড **ZKBio Zlink (Minerva IoT)** সাধারণ ব্যবহারকারীদের সরাসরি কোনো পাবলিক REST API বা Webhook প্রদান করে না। 

তাই আনন্দ পাঠশালা সিস্টেমে ডাটা পাওয়ার জন্য ২টি সবচেয়ে কার্যকর ও স্বয়ংক্রিয় পদ্ধতি তৈরি করে দেওয়া হয়েছে:

---

### পদ্ধতি ১: ক্লাউড অটোমেশন (RPA / Playwright Scraper)
* **ফাইল:** `scripts/zlink_automation_scraper.py`
* **কখন ব্যবহার করবেন:** যখন আপনি সরাসরি Zlink ক্লাউড পোর্টাল (`zlink.minervaiot.com`) থেকে ব্রাউজারের মাধ্যমে স্বয়ংক্রিয়ভাবে ডাটা আনতে চান।
* **সেটআপ:**
  ```powershell
  pip install playwright
  playwright install chromium
  ```
* **রান করার নিয়ম:**
  ১. ফাইলে আপনার Zlink ইউজারনেম ও পাসওয়ার্ড সেট করুন।
  ২. স্ক্রিপ্টটি চালান:
  ```powershell
  python scripts/zlink_automation_scraper.py
  ```

---

### পদ্ধতি ২: সরাসরি লোকাল ওয়াই-ফাই সংযোগ (Direct LAN Bridge - সবচেয়ে সহজ ও দ্রুত)
* **ফাইল:** `scripts/zk_direct_lan_bridge.py`
* **কখন ব্যবহার করবেন:** যদি আপনার ডিভাইস এবং স্কুলের কম্পিউটার একই ওয়াই-ফাই রাউটারে যুক্ত থাকে। এই পদ্ধতিতে কোনো ক্লাউড বা ইন্টারনেটের দরকার হয় না—১ সেকেন্ডে সরাসরি মেশিন থেকে ডাটা রিড হয়।
* **সেটআপ:**
  ```powershell
  pip install pyzk
  ```
* **রান করার নিয়ম:**
  ১. মেশিনের স্ক্রিন থেকে আইপি অ্যাড্রেস দেখে ফাইলে বসান (যেমন: `192.168.1.201`)।
  ২. স্ক্রিপ্ট চালান:
  ```powershell
  python scripts/zk_direct_lan_bridge.py
  ```

---

### পদ্ধতি ৩: পেনড্রাইভ বা এক্সেল ফাইল আপলোড (ম্যানুয়াল ব্যাকআপ)
যদি কোনো কারণে অটোমেশন স্ক্রিপ্ট বন্ধ থাকে, তবে সফটওয়্যারের **"উপস্থিতি মডিউল" > "ফাইল/USB আপলোড"** অপশন ব্যবহার করে Zlink থেকে ডাউনলোড করা এক্সেল/CSV ফাইল সরাসরি ১-ক্লিকে ইমপোর্ট করতে পারবেন।
